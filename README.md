# Imposter
Imposter is a fun little mobile game made with React Native, it's made to be played irl in a group of friends,
one of them is picked randomly to be the imposter and the rest will have a word, the imposter's job is to not get caught.

# why i built it
I built it so i can add all the themes i want and play it with my friends!

# IMPORTANT INFORMATION
it's a bit minimalistic for now, i'll add more to it the next season with something that fits next season's themes

# how to test (ANDROID ONLY)
 Download the APK file in the [git release](https://github.com/MustafaBioS/Imposter/releases/tag/android)<br>
 Choose a theme, Players, etc...<br>
 Start playing with a group of friends!

# inspiration
Inspired by other imposter games lol

# Theme
This project follows the "Offline" theme as it doesn't need any internet connection to be played!
